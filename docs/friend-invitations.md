# 방장 친구 초대

Jira [S15P21C204-210](https://ssafy.atlassian.net/browse/S15P21C204-210), W07/W13 일부.
운영 GitLab 프로젝트 팀원 제한을 유지한다. 일반 게스트/단일 공개 대상 설정은 후속이다.

## 동작과 권한

대기방과 장치 점검의 현재 접속 방장에게 링크 만들기·복사·재발급·회수를 제공한다.
다른 방 만들기에 쓸 수 없는 현 방 참가 전용 난수 초대이며 최대10분 동안 유효하다.
서버는 원문 대신 digest만 저장하고 방마다 가장 최근 초대 하나를 추적한다.
새 발급에 실패하면 기존 서버 초대는 보존한다. 웹은 처리 결과를 모르는 경우 이전 링크를
숨기고 재발급/회수로 결과를 확정하도록 안내한다.

- `POST /api/sessions/current/invitation`: 빈 본문, 현재 게임 세션 Bearer, 성공201.
- `DELETE /api/sessions/current/invitation`: 같은 인증/빈 본문, 성공204. 반복 회수 허용.
- 외부에서 방 코드·행위자·TTL·운영 권한을 지정할 수 없다. 예약만 한 세션과 비방장,
  이미 떠난 방장과 경기 중 요청은 거절한다. 실제 방장 교체는 다음 요청에서 다시 확인한다.
- 기존 HTTP/IP·행위자 상한을 공유한다. 신규 초대는 OPEN에서만 허용하며,
  회수는 DRAINING에서도 가능하다. 방 폐기·초대 만료 뒤 관련 초대도 정리한다.

회수/재발급은 이전 초대와 그 초대에 의존한 미접속 RESERVED 세션을 함께 무효화한다.
`onAuth`를 이미 통과한 접속도 최종 `onJoin`에서 새 세션 상태를 확인하므로 입장이 거절된다.
이미 참가한 사람과 회수 중인 참가자의 좌석은 보존한다. 최초 예약은60초 또는 초대 만료 중
빠른 기한까지이며 접속 뒤에는 기존 세션 임대/최대 수명 정책을 따른다.

팀원도 명시한 초대가 잘못됐으면 그 요청은 거절한다. 초대를 명시하지 않은 팀원의 방 코드
참가는 계속 가능하므로 모든 새 입장을 막으려면 방 잠금을 사용한다. 초대 회수가 강퇴나
팀원 권한 취소를 대신하지 않는다.

## 화면과 검증

공유 URL은 현 origin의 `/#invite=...&room=...`이며 게임 세션 토큰을 포함하지 않는다.
수신 화면은 fragment를 읽은 뒤 주소에서 지운다. 초대는 웹 메모리에만 두며 만료 시 링크/
복사를 숨긴다. 클립보드 거절 시 읽기 전용 입력의 전체 선택으로 직접 복사할 수 있다.
방장 화면 이탈은 진행 요청을 취소하고 지연 결과를 무시한다.

실제 bootstrap/HTTP/Colyseus SDK의 호스트 권한·재발급 입장 경합·예약 기한·SSO·폐기·
제한·실패 보존을 포함한 서버5파일32회귀와 브라우저2파일11개를 통과했다.
브라우저 초대 패널은 실제 React 컴포넌트와 합성 HTTP 응답을 사용한다.
`apps/web/test-fixtures/room-invitation.html`은 Vite 개발 전용 입력이며 제품 빌드에 넣지 않는다.
실제 제품6화면 완주·Cloud/실장치 인수를 이 결과로 대체하지 않는다.
전체 검사·MR/배포 상태는 [구현 기록](mvp-implementation-progress.md)을 따른다.
