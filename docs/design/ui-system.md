# 까꿍 UI 디자인 시스템

2026-09-21 기준(S15P21C204-295). 토큰의 원본은 [styles.css 의 `:root`](../../apps/web/src/styles.css)이고,
기준이 되는 화면은 **혼자 체험의 일시 정지 창**이다. 새 화면을 만들 때는 그 창을 먼저 열어 보고 맞춘다.

## 한 문장

**까꿍은 공포 게임이다. 화면은 캠코더 뷰파인더고, UI는 오래된 종이에 눌러 찍힌 자막이다.**
플레이어가 보는 것은 어두운 복도와 나트륨등 불빛이어야 하고, UI는 그 장면을 가리거나 밝히지 않는다.

## 원칙 여섯 가지

1. **무대가 먼저다.** UI는 가장자리에 붙고 가운데는 비운다. 창을 띄울 때도 장면은 뒤에서 비친다.
   비치는 정도는 한 겹이 아니다. 덮개는 장면을 살짝 누르고, 그 위의 창이 왼쪽은 짙고 오른쪽으로
   갈수록 옅어진다. 멈춘 동안 무대 HUD 는 물러난다.
2. **선은 자로 긋지 않는다.** 구분선·테두리는 `filter: url(#rough-line)` 로 흔들고 번지게 한다.
   한 가닥 안에서 진하기도 들쭉날쭉해야 한다(`--rough-ink`). 1px 선을 그대로 흔들면 계단이 보이므로
   3px 로 잡고 위아래를 투명으로 지운다. 필터는 [`RoughDefs`](../../apps/web/src/features/game/flow/RoughDefs.tsx)
   가 앱에 한 번만 둔다.
3. **글꼴은 둘이다.** 제목은 명조(나눔명조, `--font-display`), 본문·조작은 시스템 고딕
   (`--font-body`·`--font-control`). 숫자·시간·키 이름은 고정폭(`--font-mono`). 한글에 자간을 넓히면
   글자가 흩어지므로 제목·메뉴는 0.01em 안팎, 짧은 머리말에만 0.4em 이상을 준다.
4. **색은 넷이다.** 잉크(바탕), 뼛빛(글자·선), 나트륨(강조 하나), REC 빨강(녹화·위험). 그 밖의 색은
   3D 장면에서 오는 역할색(술래 적갈·도망자 청록)과 장비 표시등뿐이다. 파랑·초록 계열 UI 색은 없다.
   "성공"도 초록이 아니라 뼛빛으로, 줄 긋기·체크 같은 형태로 말한다.
5. **채우지 않는다.** 단추는 테두리와 글자뿐이고, 올리면 나트륨으로 바뀐다. 채운 단추는 홈의 주
   행동 하나에만 남는다. 카드 안의 카드, 둥근 모서리, 유리 흐림, 큰 그림자는 쓰지 않는다.
6. **움직임은 장면의 것이다.** UI는 150ms 이하의 색 전환만 한다. 예외는 화면을 흉내 내는 질감뿐이다.
   내 캐릭터 창의 주사선·잡음과 판 위의 먼지는 남기되, 동작 줄이기 설정에서는 멈춘다.

하지 말 것을 한 줄로: 둥근 모서리, 채운 단추, 왼쪽 강조 띠, 맥동하는 테두리, 유리 흐림, 파란 강조색,
이모지 아이콘, 자로 그은 1px 선.

### 글꼴·크기

- 제목 `--font-display`(명조) · 본문·조작 `--font-body`/`--font-control`(시스템 고딕) · 숫자 `--font-mono`.
  `check-product-assets` 가 본문 세 토큰이 고딕 스택인지, 글꼴 파일 여섯 개의 바이트가 맞는지 본다.
- 크기 단계는 12(보조) · 13~~14(본문·조작) · 17~~21(갈래 제목) · 30~46(창 제목). 사이 값을 새로 만들지 않는다.
- 제목은 굵게 하지 않는다. 큰 제목에는 글리프 안에서만 도는 얼룩(`background-clip: text`)을 얹어
  오래된 인쇄처럼 보이게 한다.

### 형태·간격

- 모서리 `0`. 그림자는 창 하나를 띄우는 용도로만(`0 0 120px #000a`).
- 간격은 4·8·16·32(`--space-1..4`). 무대 가장자리 여백은 24px(작은 화면 14px).
- 스크롤은 가는 선 위를 짧은 금색 선이 지난다. `scrollbar-width`·`scrollbar-color` 를 쓰면 크롬이
  `::-webkit-scrollbar` 규칙을 통째로 무시하므로 **쓰지 않는다**.

## 부품

| 창(일시 정지)   | 덮개 + 창 두 겹. 머리·왼쪽 메뉴·오른쪽 내용·발치 키 안내. 크기는 갈래를 바꿔도 고정이고 내용만 구른다.          |
| 메뉴 항목       | 글자만. 고른 줄에 `▶` 와 오른쪽으로 잦아드는 금색 밑줄, 글자에 은은한 번짐. 나가기는 선 아래로 떼고 빨강 hover. |
| 단추            | 테두리 + 글자. hover 는 나트륨, 비활성은 흐린 뼛빛. 채운 단추는 홈의 주 행동 하나뿐.                            |
| 키 캡(kbd)      | 바탕 없음, 각진 테두리, 고정폭. 창 발치의 Esc 는 크게.                                                          |
| 표(키·상태)     | 왼쪽 이름, 오른쪽 값, 행마다 닳은 선. 준비됨이면 나트륨, 실패면 REC.                                            |
| 갈래 제목       | 명조, 오른쪽으로 선이 뻗는다.                                                                                   |
| 게이지·슬라이더 | 가는 선 위를 금색이 채우고, 손잡이는 발광하는 마름모.                                                           |
| 동의            | 카메라를 켜는 모든 길이 지나는 확인 창. 약관은 상자 안에서 구르고, 동의 전에는 카메라가 켜지지 않는다.          |
| 내 캐릭터 창    | 우상단 4:3. 창 안 아래 34px 는 게이지 띠. 주사선·비네트·캔버스 잡음을 얹는다.                                   |
| 미니맵          | 잉크 판 안의 정사각형 창. 바닥 `#2a2823`, 벽 뼛빛, 나는 뼛빛 점, 시야는 흰 부채꼴, 내 출구 번호는 나트륨.       |
| 핫바            | 정사각형 칸 다섯. 번호는 왼쪽 위, 개수는 오른쪽 아래, 가운데는 글리프. 고른 칸만 나트륨 테두리.                 |
| 상호작용 안내   | 십자선 아래 키 캡 하나와 짧은 문구. 판 없이 글자만.                                                             |

## 새 화면을 만들 때

1. 무대 위에 꼭 있어야 하는지 묻는다. 아니면 Esc 메뉴나 홈 옵션으로 보낸다.
2. 판 하나, 글자, 필요하면 키 이름. 뼛빛에서 시작하고 강조가 꼭 필요할 때만 나트륨 하나.
3. 선은 `--rough-ink` + `filter: url(#rough-line)`. 단추는 테두리만.
4. 토큰만 쓴다. 새 16진수 색을 `styles.css` 에 적어야 한다면 이 문서에 먼저 줄을 추가한다.
