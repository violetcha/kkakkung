# 미디어 수명

2026-09-13 · 코드 기준 `99f90baa`. 제품 범위와 공개 전 과제는 [현행 기획서](spec/current.md)를 따른다.

게임 참가자와 미디어 연결 세대는 서로 다른 수명이다.

`retireMediaGeneration`은 구 mediaGeneration의 게시용 가공 트랙, 수신 트랙, 음성 그래프, SDK 재연결, 관련 텍스처를 정리한다. 정상 세대 교체에서는 논리 playerId와 경기 참가 자격, 유효한 게임 Room 연결을 유지한다. 구 세대 회수가 확인되기 전에는 새 Identity와 토큰을 발급하지 않으며 폐기한 Identity를 재사용하지 않는다.

`endParticipation`은 개인 종료, 실제 퇴장, 매치 종료에 따라 입력과 참가 자격을 끝낸다. 개인 결과와 재경기에 필요한 Room 연결·결과·누계·출구 기록은 규칙에 맞게 유지할 수 있다. 실제 퇴장이나 게임 연결 상실에서는 장치, Worker, timer/listener와 게임 연결까지 정리한다.

원본 카메라는 devices가, 게시용 가공 트랙은 media가 소유한다. 정상 세대 교체는 원본 장치를 유지할 수 있다. 카메라나 추론 장애만으로 참가 종료를 호출하지 않고 보조 입력과 안전 얼굴로 전환한다.

제품 경로에는 LiveKit 연결·세대별 토큰 발급/회수·지속 저널·복구가 구현되어 있다. 게임 소켓 종료 후 진행 경기 복귀와 서버 재시작 시 매치 복원은 지원하지 않는다. 현재 `publisher-permissions`는 정상 팀원 6명·1방의 내부 시험 범위이며, 모듈 구현이나 합성 미디어 시험을 공개 권한 G1·실장치 G5·통합 부하 G6 인수 완료로 계산하지 않는다. 실제 시험 절차는 [6인 시험 안내](six-player-test.md)를 따른다.
