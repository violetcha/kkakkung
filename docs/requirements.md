## 1. 개요

### 1.1 제품

까꿍은 웹캠으로 몸과 고개를 움직여 조작하는 6인(도망자 3 · 술래 3) 1인칭 미로 술래잡기다. 참가자의 가공된 흑백 얼굴이 아바타 머리에 붙고, 가까운 사람의 목소리만 들린다. 이동·포획·승패는 서버가 판정한다.

### 1.2 표기

| 칸       | 값                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ID       | `FR-<영역>-<번호>`(기능), `NFR-<영역>-<번호>`(비기능)                                                                                                  |
| 우선순위 | **필수**: MVP에 반드시 있어야 함. **선택**: 있으면 좋고 없어도 제품이 성립함                                                                           |
| 상태     | **구현**: 코드와 자동 시험이 있음. **부분**: 일부만 있음. **실장치 미검증**: 코드는 있으나 실제 6인·Cloud 확인이 저장소 밖. **제외**: 이번 범위에서 뺌 |
| 근거     | 기획서 절 번호. `API`는 API 설계서                                                                                                                     |

## 2. 사용자와 역할

| 사용자      | 설명                                                                                            |
| ----------- | ----------------------------------------------------------------------------------------------- |
| 참가자      | lab.ssafy.com SSO로 로그인한 SSAFY 교육생. 방을 만들거나 참가해 경기한다                        |
| 방장        | 방을 만든 참가자(나가면 가장 먼저 들어온 사람). 입장 잠금·내보내기·맵 크기·시작·재경기를 정한다 |
| 도망자      | 경기에서 자기 출구로 탈출하는 역할(일반 방 3명)                                                 |
| 술래        | 경기에서 도망자를 포획하는 역할(일반 방 3명)                                                    |
| 관전자      | 탈출·포획으로 경기에서 빠진 도망자. 살아 있는 도망자의 시점을 본다                              |
| 운영자      | 팀원. 데모·시연 방을 열고 서버를 drain·resume한다(등록 이메일·운영 토큰)                        |
| 발표 참가자 | 시연 방(2:2)에서 정해진 자리로 경기하는 사람                                                    |
