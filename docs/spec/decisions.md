# 최신 제품 결정 정정표

갱신일: 2026-09-08 · 결정 ID: **D-2026-09-08-01**

사용자의 최신 명시 결정이 보관 중인 v0.0.8 원본과 실행계획보다 우선한다. 원본 HTML·DOCX는 당시 문서로 보존하며, 아래 정정을 반영하지 않은 원본의 아이템 내용을 현재 승인 요구로 실행하지 않는다.

## 도망자 아이템은 미정

사용자 결정: **“아직 도망자 아이템은 미정인데 이걸 끼워넣은건 잘못됐어.”**

종류·효과·수량·배치·획득·소지·사용 방법은 결정 대기다. 이전 실행 문서의 소리 미끼/해제 도구, 3+3 배치, 단일 슬롯, 자동 획득, 특정 거리·지속시간·즉시 해제는 승인된 제품 요구가 아니다. AI가 대체 아이템이나 임의 규칙을 결정하지 않는다.

| 처리                  | 작업                                                                             |
| --------------------- | -------------------------------------------------------------------------------- |
| 전체 실행 보류        | MP-06, EQ-06, EQ-07, EQ-08, EQ-09, EQ-12                                         |
| 확정 부분만 진행      | EQ-11의 구속 상태·남은 시간 HUD                                                  |
| 아이템 연결 부분 제거 | 프로토콜·Tick 단계·맵 선발 조건·연습/경기 초기화·입력·음향·QA의 아이템 전용 부분 |
| 유지                  | 술래 감지기·덫, 1.5초 구속·자연 만료·2초 유예·회전·포획, 공통 순환 우선순위      |

보류된 ID와 담당 고정 번호는 추적용으로 유지한다. “오늘 1–5번”에 보류 번호가 포함되면 그 번호를 구현·커밋하지 않고 보류 상태를 기록한 뒤 요청 범위의 다음 번호를 수행한다. 보류 작업의 완료 체크나 기능을 대신하는 성공 stub을 만들지 않는다.

## 검수와 범위 보고

원본 122개 번호 중 **116개는 현재 확정 범위의 실행 대상, 6개는 제품 결정 대기**다. 숫자를 맞추려고 미정 기능을 구현하지 않는다. EQ-11처럼 축소된 작업은 현재 완료 조건으로 검증한다.

G3의 아이템 획득/사용 전용 사례(G3-C)와 G5의 아이템 필수 행동은 `PRODUCT_DECISION_PENDING`으로 별도 기록한다. 나머지 게임·장비·출구·미디어·운영·실기기·부하 조건은 유지한다. 확정 범위를 모두 통과하면 **D-2026-09-08-01 적용 확정 범위 완료**로 보고할 수 있지만, 원본 v0.0.8 전체 완료나 아이템의 승인된 영구 제외로 바꾸지 않는다.

아이템 재개에는 사용자의 종류·효과·획득·소지·사용·배치 및 MVP 포함 범위 결정이 필요하다. 결정 후 해당 ID·생산자/소비자 계약·검수 조건을 함께 갱신한다. 이번 보완은 새로운 아이템 기획을 대신 확정하는 작업이 아니다.

## 연결 계약 보완

[EXEC-CONTRACT-3 공통 원본](../execution/common.md)과 [검사 가능한 타입](../execution/contracts/types.ts)을 적용한다. 기존 명령의 접수/종결, 수신자·송신자 세대, 센서별 관측 시각 등의 계약을 유지하고 맵 영역·fallback 출처, 연습/본경기 논리 인스턴스, 미디어 초기화와 준비·입장 상태의 구분을 보완했다. HTTP 매칭 처리 전 Origin 검사와 외부 접근을 격리한 배포 시험 순서도 담당 계획에 반영했다.

이는 확정 기능을 연결하기 위한 구현 계약의 보완이다. 제품 결정 ID와 원본 122개 번호·116개 실행/6개 결정 대기는 유지하며 도망자 아이템을 새로 확정하지 않는다. 서버 보안 코드와 Jenkins 배포 구현은 각각 B와 F의 실제 구현·검증 작업으로 남는다.

이 계약·fixture의 검사 통과는 계획 정합성 증거다. 실제 제품 구현, Cloud 권한, 6대 완주, 10방 성능의 통과를 뜻하지 않는다.
