# 개인 소리 점검과 수신 제어

Jira [S15P21C204-194](https://ssafy.atlassian.net/browse/S15P21C204-194), MVP W11·W13.

## 사용 흐름

홈의 개인 체험과 실제 방의 장치 점검/팀 연습에서 **확인음 듣기**로 출력 장치를 확인한다.
확인음만 누르면 카메라나 마이크를 취득하지 않는다. 브라우저가 재생을 거절하면 재시도를 안내한다.
카메라 필수·마이크 선택이라는 실제 경기 조건을 바꾸지 않는다.

선택한 마이크를 켜면 순간 입력 크기를 보여준다. 이 막대는 입력 존재 여부를 점검하는 용도이며
음질·원격 수신·음성 지연이 통과했다는 표시는 아니다. 마이크를 끄면 해당 분석 노드를 해제한다.
마이크를 스피커에 연결하거나 음성을 녹음·저장·업로드하지 않는다.

듣는 음량은 기본 70%, 0–100%다. 전체 소리 끄기는 목소리와 게임 효과음에 함께 적용한다.
친구별 음소거는 현재 방 명단의 상대 목소리에만 적용한다. 상대 화면이나 상대 마이크를 제어하지 않는다.
서버가 현재 허용한 소리에만 적용되며 거리·차단·COUNTDOWN·종료·권한 상실의 출력 잠금을 열지 않는다.

## 소유권과 수명

- 기존 장치 AudioContext를 재사용한다. 확인음은 660Hz·350ms로 제한하고 중복 클릭 시 이전 노드를 정리한다.
- 확인음은 활성 DEVICE_CHECK/TEAM_PRACTICE에서만 허용한다. 지연된 재생 잠금 해제 후에도 단계·음소거·종료를 다시 확인한다.
- 마이크 분석은 선택한 원본 트랙을 빌려 사용한다. 소스 변경·종료·비활성 탭·Context 정지에서 분리한다. 원본 트랙 중지는 DeviceManager가 담당한다.
- 경기 정책 gain과 사용자 gain을 따로 보관한다. 정책 제외·playerId 또는 게시 세대 변경은 기존 체인을 정리한다. 사용자 설정 변경만으로 누락 트랙을 만들지 않는다.
- 같은 방의 재경기/미디어 세대 교체에는 개인 설정을 유지한다. 방 명단에서 사라진 ID는 지우고, 퇴장·연결 상실·개인 체험 재시작에서는 기본값으로 돌아간다. 브라우저 영구 저장소에 남기지 않는다.
- Cloud 배포 harness는 로컬 장치 분석을 제공하지 않으므로 분석값은 null, 확인음은 unavailable이다. 이 adapter를 실제 소리 점검의 성공 증거로 사용하지 않는다.

## 검증

AudioGraph의 정책·잠금·세대·신원·음량 상한, 분석 노드의 단일 소유와 종료, Runtime의 지연 응답,
재경기·명단 변경·방 종료를 단위/조립 회귀로 검사한다. 문서 계약 원본·타입·fixture와 사본도 동기화한다.

브라우저 시험은 실제 AudioContext와 합성 PCM을 사용해 출력 재사용, 입력 막대, 마이크 종료,
개인 체험 재진입의 초기화를 검사한다. 실제 사람의 마이크/스피커, LiveKit 원격 품질,
6대 장치 동시 플레이와 공개 미디어의 금지 수신 인수는 별도다.
전체 검사와 원격 CI·MR·배포 상태는 [구현 기록](mvp-implementation-progress.md)을 따른다.
