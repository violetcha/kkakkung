# 개인 사전 점검과 조작 체험

Jira [S15P21C204-193](https://ssafy.atlassian.net/browse/S15P21C204-193), MVP 실행계획 W08.

## 진입과 경기 연결

홈에서 6인·PC·카메라 필수/마이크 선택, 승리 목표와 준비 순서를 안내한다. **혼자 장치 점검·조작 체험**은 닉네임이나 방 생성 전에도 진입한다. 배포 도메인의 GitLab 팀원 제한은 유지한다.

체험을 마친 뒤 닉네임·방 생성/참가 화면으로 돌아간다. 실제 경기의 DEVICE_CHECK, 카메라 필수 조건, 6인 팀 연습을 건너뛰지 않는다. 개인 체험의 보정·장치·지도·장비·성공 기록을 방에 전달하지 않는다.

## 실제 동작

- 기존 InteractionRuntime과 interaction-bridge를 통해 키보드, 실제 장치 취득, 모델 Worker, 중립 보정, 얼굴/상체 입력을 사용한다. 체험 진입만으로 카메라를 취득하지 않는다.
- 연습실은 웹에 공개 가능한 별도 3×5 바닥과 외벽이다. 실제 서버 맵, seed, game-core나 개발용 fixture를 import하지 않는다.
- 같은 제품 렌더러로 첫 시점을 보여준다. 전진/후진은 한 칸 행동 완료, 좌우 회전은 90도 행동 완료 후 기록한다. 키 반복은 기존 입력 처리기가 거절하고 로컬 회전 대기는 하나만 보관한다.
- 중립 성공은 사용자가 이동 입력을 해제하고 행동이 끝난 뒤 0.5초 이상 멈출 때 기록한다. 모션에서는 신선한 유효 얼굴·상체와 보정 상태를 확인한다. 입력 만료, 포커스 상실, 문맥 재설정은 중립 성공으로 계산하지 않는다.
- 도망자 체험은 내 출구 앞에서 E로 시작한다. 기존 자세 유지 판정으로 양팔 Y자를 1.2초 유지하거나 기존 방향키 순서를 완성한다. 시간 초과·취소·반복 키·잘못된 키를 처리하며 모드 전환 시 중간 진행을 지운다.
- 술래 체험은 벽 앞에서 1/2 장비 선택, F 또는 V 손동작으로 설치한다. 벽/재고/행동 잠금을 확인하고 설치 완료 후에만 기록한다. F 취소 및 새 역할 체험의 위치·장비 초기화를 처리한다.
- 개인 연습의 행동·설치·도전은 학습용 로컬 판정이다. 실제 포획, 상대 지도 교환, 원격 음성/얼굴, 승패·밸런스 시험을 대체하지 않는다. 도망자 아이템은 추가하지 않는다.

## 실패와 자원 수명

개인 체험의 **소리 점검 · 음량**에서 카메라 없이 확인음을 듣고, 선택한 마이크의 입력 크기를
확인한다. 듣는 음량·전체 음소거는 현재 체험에만 유지한다.
자세한 동작과 검증 범위는 [개인 소리 점검](audio-controls.md)을 따른다.

얼굴 부족·상체 부족·표본 부족·불안정 보정, 모델 오류·권한 거부·장치 상실을 복구 문구로 표시한다. 설정을 접어도 오류는 보인다. 카메라 없이 키보드로 체험할 수 있지만 실제 경기 준비 조건은 유지한다.

포커스를 잃으면 입력·진행 중 행동을 중단한다. 탭이 숨겨지거나 페이지가 이동하면 전체 체험을 닫아 카메라/마이크 트랙·Worker·타이머·오디오·미리보기를 정리한다. 다시 시작은 새 세션이며 카메라는 직접 다시 켜야 한다. 닫기 중 늦게 허용된 장치 응답도 해당 옛 세션에서 회수한다.

Room 연결, 좌석 예약, 미디어 grant, publish/subscribe는 하지 않는다. 의도하지 않은 미디어 요청은 실패하도록 구성한다. 성공 stub이나 READY 메시지로 제품 준비 상태를 위조하지 않는다. 기존 홈의 접속 방식 읽기와 장치 모델 자산 다운로드는 남는다.

## 검증과 한계

- 로컬 회귀 9개: 실제 Runtime 키 처리기, 행동 완료, 벽/설치/도전 제한, 중립과 시간 만료 구분, 포커스·역할 전환, 지연 권한 취소, 새 세션 상태를 확인했다.
- 브라우저 3개: 키보드와 양 역할 완주, 방/미디어 요청 부재, 실제 모델 Worker/AudioContext와 합성 카메라 수명, 숨김 이벤트와 지연 권한 응답 정리를 확인했다.
- Vite 개발용 소켓은 subprotocol로 구분한다. 이를 게임 연결로 집계한 첫 시험 실패는 관측 코드에서 수정했다.
- 사람의 카메라, 마이크, 모션 성공률·체감 지연·공포감은 아직 실측하지 않았다. 합성 영상은 실제 얼굴/포즈 인수의 대체가 아니며 숨김 시험은 브라우저에서 해당 이벤트를 재현한 것이다.
- 전체 pnpm verify, 원격 CI·MR·배포 상태는 [구현 진행 기록](mvp-implementation-progress.md)의 실제 결과를 따른다.
