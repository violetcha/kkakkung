# 아이디어 검토

## 교육과 게임을 결합한 후보

아이디어 조사 이후에는 사용자가 직접 참여하고 결과를 체감할 수 있는 게임·교육형 서비스를 중심으로 후보를 검토했다.

## 오늘도 AI가 사고쳤다

잘못된 AI 결과의 원인을 찾아 해결하는 학습 게임이다. 사용자는 AI 조사관이 되어 데이터 분포, 혼동 행렬, 학습 그래프 등의 증거를 선택하고 문제의 원인을 진단한다.

```text
AI 사고 발생
→ 필요한 증거 선택
→ 원인 진단
→ 해결 방법 적용
→ 결과 재확인
→ 관련 AI 개념 학습
```

기존 강의처럼 개념을 먼저 외우는 것이 아니라, 문제를 해결한 후 자신이 경험한 현상에 개념 이름을 붙인다는 점이 특징이다. AI 학습을 설명 중심에서 문제 해결 중심으로 바꿀 수 있는 아이디어라고 생각했다.

## 끊고 확인: 7일

가상의 스마트폰에서 전화, 문자, 메신저, 은행 앱 등을 조작하며 7일 동안 이어지는 보이스피싱 공격에 대응하는 게임이다.

첫날 알려준 주소나 가족 정보가 며칠 뒤 더 정교한 사칭에 사용될 수 있다. 반대로 공식 연락처 저장, 가족 확인 암호 설정, 통화 녹음 등의 행동은 이후 위기에서 방어 수단이 된다.

| 과거 행동 | 이후 발생하는 변화 |
| --- | --- |
| 가족 연락처 제공 | 실제 가족 이름을 이용한 사칭 발생 |
| 문자 속 번호로 재연락 | 가짜 고객센터가 이전 상황을 알고 접근 |
| 악성 앱 권한 허용 | 같은 휴대전화의 확인 수단이 불안정해짐 |
| 공식 연락처 저장 | 위기 상황에서 안전한 확인 경로 확보 |
| 다른 기기 확보 | 침해된 휴대전화 대신 금융기관에 연락 가능 |

한 문제씩 정답을 맞히는 방식이 아니라 작은 선택이 이후의 공격과 방어 방법을 바꾼다는 점이 핵심이다.

## BLACK TRACE

서로 다른 정보를 가진 플레이어들이 같은 미로에서 추격하는 2D 비대칭 게임이다. 탈출자는 자신이 지나온 길을 기억하고, 술래는 자신이 만든 벽과 주변 정보만 기억한다.

게임이 끝나면 서버에 저장된 이동 기록을 바탕으로 정확한 리플레이를 만든다. AI는 이 기록에서 주요 장면을 선택해 짧은 하이라이트 영상으로 재구성한다.

> AI는 승패를 판단하지 않는다. 실제 경기 기록을 기반으로 경기 후 콘텐츠를 만드는 역할을 담당한다.

이 구조는 AI 생성 결과가 부정확하더라도 원본 리플레이를 제공할 수 있어 핵심 게임 경험이 깨지지 않는다는 장점이 있다.

## 후보를 검토하며 세운 원칙

- AI를 제거했을 때 핵심 경험이 달라져야 한다.
- AI가 중요한 판정을 임의로 결정하지 않게 한다.
- 사용자의 선택이 다음 상황에 실제로 영향을 줘야 한다.
- 핵심 기능을 작은 MVP로 먼저 구현할 수 있어야 한다.
- 프론트엔드, 백엔드, AI 역할이 명확해야 한다.

## 정리

AI를 게임에 추가하는 것만으로는 차별점이 되지 않았다. AI가 핵심 경험에서 담당하는 역할과 규칙 기반 시스템이 담당하는 역할을 명확하게 구분해야 아이디어의 설득력과 구현 가능성이 높아진다는 점을 알게 되었다.
