# 기존 사례 조사

## 아이디어를 현실적으로 바라보기

구체화한 아이디어가 실제로 차별성이 있는지 확인하기 위해 유사 서비스와 기존 사례를 살펴보았다. 새롭다고 생각한 아이디어도 이미 비슷한 서비스가 운영되고 있는 경우가 많았다.

| 아이디어 | 조사 결과 | 판단 |
| --- | --- | --- |
| 산업현장 안전 관리 | 유사한 상용 서비스가 많음 | 단순 탐지만으로 차별화 어려움 |
| 침수 조기 경보 | 일부 유사 사례 존재 | 데이터 확보와 검증이 어려워 보류 |
| 반려동물 행동 분석 | 유사 서비스 존재 | 새로운 사용자 경험 필요 |
| 매장 구매 전환 분석 | 관련 스타트업과 솔루션 존재 | 데이터 확보와 차별화가 어려움 |
| 체험형 안전교육 | HMD·센서 기반 사례 존재 | 웹캠 기반 접근으로 심화 가능 |
| AI 소개팅 훈련 | 일부 유사 서비스 존재 | 반복 훈련 구조를 중심으로 발전 가능 |

조사를 통해 단순히 무엇을 탐지하는지를 강조해서는 기존 서비스와 구분하기 어렵다는 결론을 얻었다.

> 무엇을 탐지하는가보다, 탐지 결과로 사용자가 무엇을 할 수 있는가가 중요하다.

## AI의 역할 다시 생각하기

생성형 AI가 서비스의 모든 결과를 결정하게 하면 결과가 매번 달라지고 중요한 판정을 검증하기 어렵다. 따라서 핵심 상태와 성공·실패 판정은 규칙으로 관리하고, AI는 자연어를 구조화하거나 상황에 맞는 표현을 만드는 역할을 맡는 방향이 적절하다고 생각했다.

이 원칙을 바탕으로 AI가 게임의 규칙이나 시뮬레이션에 참여하는 아이디어도 살펴보았다.

### 현실 패치노트

사용자가 사회의 문제를 해결하기 위한 정책을 만들면 AI 시민들이 그 정책의 빈틈을 찾아 행동한다. 사용자는 문제를 해결하려고 만든 규칙이 어떤 새로운 문제를 만드는지 확인하고 다시 정책을 수정한다.

### 한 문장 종족전

사용자가 생물의 행동 원칙을 한 문장으로 작성하면 AI가 실행 가능한 규칙으로 변환한다. 실제 이동과 경쟁은 2D 시뮬레이션에서 실행되고, 사용자는 자신의 문장이 어떤 행동으로 나타나는지 확인한다.

### 세계선 Diff

과거의 사건 한 문장을 수정한 뒤 미래가 어떻게 달라지는지 비교하는 게임이다. 작은 변화가 예상하지 못한 다른 결과를 만들 수 있다는 점을 경험하게 한다.

### 원문을 지켜라

하나의 문장이 뉴스, 번역, 밈, 숏폼 등을 거치면서 어떻게 변질되는지 확인하는 미디어 리터러시 게임이다. 사용자는 원문의 핵심 의미를 최대한 보존해야 한다.

### 미래의 1점 리뷰

아직 만들지 않은 서비스 아이디어를 입력하면 다양한 미래 사용자의 실패 사례와 부정적인 리뷰를 확인한다. 이를 통해 개발 전에 예외 상황과 위험 요소를 발견할 수 있다.

## 정리

아이디어 조사 과정에서는 새로움만 보는 것이 아니라 기존 서비스, 데이터 확보, AI의 필요성, 결과의 재현성까지 함께 확인해야 했다. 또한 AI가 모든 것을 자유롭게 생성하는 구조보다 AI와 규칙 엔진의 역할을 나누는 방식이 프로젝트의 완성도를 높일 수 있다고 판단했다.
