## 1부. 아이디어 발산 — 영상 AI 4안

### 1. 🦺 산업현장 안전사고 예방 AI

**한 줄 소개:** CCTV 영상에서 위험 상황을 실시간 탐지해 관리자에게 알려주는 안전 관제 서비스

**탐지 대상**

- 안전모 미착용
- 안전조끼 미착용
- 위험구역 진입
- 화재 / 연기 발생

**서비스 흐름**

```
CCTV 영상 → AI 분석 → 위험 이벤트 감지 → 관리자 화면 실시간 알림
```

> ⚠️ **조사 결과: 이미 상용 서비스가 존재한다.** → 후보에서 제외

---

### 2. 🌊 침수 조기 경보 AI

**한 줄 소개:** 도로·하천 CCTV 영상을 분석해 침수가 일어나기 **전에** 위험을 알려주는 서비스

**분석 단계**

```
평상시 하천 → 수위 상승 → 물살 변화 → 위험 수준 판단
```

**탐지 대상**

- 하천 수위 변화
- 물이 넘치는 지점
- 산책로 침수
- 사람 / 차량의 위험구역 진입

> 4안 중 유일하게 "이미 있음" 판정이 나지 않은 아이디어.
> 다만 **재난 상황 데이터 확보와 검증이 어렵다**는 점이 걸림돌.

### 3. 🐶 반려동물 행동 번역 AI

**한 줄 소개:** 강아지 영상을 분석해 지금 어떤 감정·상태인지 사람 말로 번역해주는 서비스

**분석 요소**

- 꼬리 움직임
- 귀 방향
- 자세
- 짖음 (소리)

**출력 예시**

> 🗨️ "현재 낯선 환경에 **경계**하는 행동이에요"
>
> 🗨️ "지금 **놀이 욕구**가 높은 상태예요"

> ⚠️ **조사 결과: 이미 있다.** → 후보에서 제외

### 4. 🛒 매장 구매 전환 분석 AI

**한 줄 소개:** 매장 영상으로 고객 행동을 분석해 진열·물량 의사결정을 돕는 리테일 인사이트 서비스

**데이터셋:** `RetailAction`

**분석 항목**

| 영상에서 보는 것             | 도출되는 인사이트 |
| ---------------------------- | ----------------- |

| 어떤 상품 앞에 오래 머무는지 | 관심도            |
| 집었다가 내려놓는 상품       | 구매 고민         |
| 왔다갔다 많은 구역           | 동선 혼잡         |
| 시간대별 행동 변화           | 시간대별 패턴     |

**분석 결과 예시**

> 📊 "A상품 진열대는 방문자의 **38%가 접근**했지만, 체류 후 **구매로 이어질 가능성은 낮음**"

**활용:** 진열 위치 개선, 물량 주문 최적화

> ⚠️ **조사 결과: 이미 스타트업이 하고 있다.** → 후보에서 제외

### 🔎 발산 단계에서 배운 것

4개 중 **3개가 이미 존재하는 서비스**였다.

- "기술적으로 만들 수 있는가"보다 **"이미 누가 하고 있는가"를 먼저 확인**해야 시간을 아낀다.
- CCTV + 객체탐지 조합은 진입장벽이 낮아서 이미 시장이 형성돼 있다.
  → 단순 탐지가 아니라 **탐지 결과를 무엇으로 바꿔주는가**에서 차별점을 만들어야 한다.
- 그래서 다음 단계에서는 "무엇을 탐지하는가"가 아니라
  **"사용자가 그 분석 결과로 무엇을 하게 되는가"**를 중심으로 아이디어를 다시 세웠다.

## 2부. 심화 기획 A — 🏫 몸으로 배우는 안전교육

> **한 줄 소개:** 교실 TV + 웹캠 하나로, 아이들이 실제 몸을 움직여 게임 속에서
> 지진·화재 대피를 훈련하는 서비스

### 1. 문제 정의

- 학교 지진·화재 대피훈련은 **매년 의무**지만, 방송 듣고 줄 서서 나가는 형식적 훈련에 그침
- 기존 메타버스 재난훈련은 **HMD·착용 센서 필수** → 학교가 학생 수만큼 장비를 갖출 수 없음
- 아이들은 "머리 보호", "자세 낮추기" 같은 행동을 **몸으로 익힌 적이 없음**

### 2. 서비스 흐름

```
게임 속 가상 교실에서 지진 발생
→ 웹캠이 아이의 실제 동작 인식 (책상 아래로 / 머리 보호 / 낮은 자세 이동)
→ 아바타가 내 동작을 따라 하며 미션 수행
→ 훈련 결과 리포트가 교사 대시보드에 저장
```

### 3. 핵심 기능

| 트랙             | 기능                                                                  |
| ---------------- | --------------------------------------------------------------------- |
| 🎥 영상 AI       | 웹캠 자세 추정(포즈 인식)으로 대피 동작 수행 여부·정확도 판정         |
| 🎮 메타버스/게임 | 가상 학교 맵에서 미션형 대피 훈련, 아바타 동작 동기화, 학급 협동 모드 |
| 📊 빅데이터      | 학급·학교별 훈련 데이터 축적 → "우리 반은 머리 보호 정확도 62%" 리포트 |

### 4. 기술 스택 (초안)

- **AI:** MediaPipe / YOLO-Pose 기반 실시간 자세 추정, 동작 분류 모델
- **게임:** Unity(WebGL) 또는 Three.js — 브라우저 실행으로 설치 부담 제거
- **백엔드/데이터:** Spring Boot, 훈련 로그 수집·분석 대시보드

### 5. 차별화

- 기존 연구·서비스는 HMD + 착용 센서 기반 → **우리는 장비 0원, 웹캠만으로**
- 시청형 교육 영상과 달리 **실제 몸동작을 판정**하고 데이터로 남김
- 전국 학교 의무 훈련이라는 **명확한 수요처** (B2G/B2B 확장 가능)

### 6. 기대 효과

- 아이들이 재난 대응을 놀이로 반복 학습 → 실제 상황에서 몸이 기억
- 교사는 데이터 기반으로 학급 취약 동작을 파악해 보완 교육

## 3부. 심화 기획 B — 💘 FIRST DATE AI

> 멀티모달 AI 소개팅 트레이너

### 1. 한 줄 정의

**소개팅이 어려운 사용자가 AI 상대와 실제처럼 대화하며 연습하고, 영상·음성·대화 내용을
AI가 함께 분석해 개인별 약점을 진단하고 훈련해주는 멀티모달 소개팅 시뮬레이터**

단순 연애 상담이나 답변 추천이 아니라, **실제 소개팅 상황을 반복 연습하는 훈련 서비스**를
목표로 한다.

### 2. 기획 배경 / 문제 정의

소개팅이 익숙하지 않은 사람은 실제 상황을 경험하기 전까지 자신의 문제점을 객관적으로
파악하기 어렵다.

- 어떤 질문을 해야 할지 몰라 대화가 끊긴다.
- 긴장하면 말이 빨라지거나 지나치게 길어진다.
- 상대방의 이야기를 확장하지 못하고 자신의 이야기로 넘어간다.
- 시선, 표정, 말투 등 비언어적 요소는 혼자 연습하기 어렵다.
- 기존 연애 콘텐츠는 주로 조언·메시지 추천 중심이라
  **실전 대화 연습과 객관적인 피드백이 부족하다.**

따라서 AI가 실제 소개팅 상대 역할을 수행하면서 **영상·음성·대화 패턴을 동시에 분석하고,
반복 훈련을 통해 사용자가 개선되는 경험**을 제공하고자 한다.

### 3. 타겟

| 대상                                   | 니즈                            |
| -------------------------------------- | ------------------------------- |
| 소개팅 경험이 적은 사용자              | 실제 소개팅 전에 부담 없이 연습 |
| 대화를 이어가기 어려운 사용자          | 질문·공감·대화 확장 훈련        |
| 발표·대인관계 상황에서 긴장하는 사용자 | 말속도·시선·표현 습관 확인      |

초기 MVP는 **소개팅 전 실전 연습이 필요한 사용자**에 집중한다.

### 4. 핵심 차별점

#### ① 멀티모달 통합 분석

소개팅 한 세션에서 동시에 분석한다.

- **영상**: 시선 방향, 고개 움직임, 표정 변화
- **음성**: 말속도, 침묵, filler word, 발화 길이
- **대화**: 질문 횟수, 후속 질문, 대화 확장, 독백 비율

각 기능을 별도로 제공하는 것이 아니라 **같은 시점의 행동과 대화를 연결해서 분석**한다.

#### ② DATE REPLAY

소개팅 종료 후 전체 세션을 타임라인으로 복기한다.

```
00:00 ━ 🟢 좋은 질문 ━ 🔴 긴 독백 ━ 🟡 말속도 증가 ━ 🔵 긴 침묵 ━
```

특정 이벤트를 클릭하면 해당 시점의 영상·대화 내용·AI 피드백을 함께 확인할 수 있다.

#### ③ User Dating Skill Profile

세션 결과를 단발성 점수로 끝내지 않고 사용자별 능력을 지속적으로 기록한다.

- 후속 질문
- 대화 확장
- 말속도
- 침묵 대응
- 시선 안정성
- 반응 표현

#### ④ Adaptive Persona

사용자의 약점을 기반으로 **다음 AI 소개팅 상대의 성향 자체를 변경한다.**

| 사용자 약점    | 다음 AI 상대               |
| -------------- | -------------------------- |
| 질문 능력 부족 | 단답형 AI 상대             |
| 침묵 대응 부족 | 먼저 질문하지 않는 AI 상대 |
| 경청 부족      | 이야기가 많은 AI 상대      |

즉, AI가 피드백만 제공하는 것이 아니라
**사용자에게 필요한 다음 훈련 환경까지 생성한다.**

### 5. 주요 기능

**MVP**

- AI 소개팅 상대 선택 및 음성 대화
- Webcam 기반 얼굴·시선·표정 변화 분석
- STT 기반 실시간 대화 기록
- 말속도·침묵·filler word 분석
- LLM 기반 대화 흐름 분석
- 세션 종료 후 종합 리포트
- DATE REPLAY 타임라인
- 사용자 Skill Profile
- 약점 기반 다음 AI Persona 추천

**확장 기능**

- 특정 역량 집중 훈련 모드 (후속 질문 훈련 / 침묵 깨기 / 첫 만남 3분 훈련)
- 세션별 성장 그래프
- 실제 사용자 간 모의 소개팅
- 실제 모의소개팅 후 양측 개인별 AI 피드백

### 6. AI 활용 포인트

| 기능               | AI / 기술                     |
| ------------------ | ----------------------------- |
| AI 소개팅 상대     | LLM + Persona Prompt          |
| 음성 인식          | Streaming STT                 |
| AI 음성            | TTS                           |
| 얼굴·시선 분석     | MediaPipe Face Landmarker     |
| 음성 특징 분석     | Web Audio API / Python        |
| 대화 분석          | LLM                           |
| 사용자 역량 모델링 | 행동 Feature 기반 Skill Model |
| 다음 상대 추천     | 개인화 Recommendation         |
| 사후 피드백        | LLM + Session Data            |

핵심은 LLM 한 번 호출하는 것이 아니라,

```
영상 + 음성 + 대화 → 사용자 행동 분석 → Skill Profile → 다음 Persona 생성
```

으로 이어지는 **멀티모달 개인화 루프**다.

### 7. AI 파이프라인

```
사용자 Webcam ──→ 얼굴·시선·표정 특징 추출 ──┐
                                             ├──→ Multimodal Analysis
사용자 Mic ──→ STT ──→ 음성 특징 + 대화 내용 ─┘
                                                       ↓
                                                실시간 간단 코칭
                                                       ↓
                                                  DATE REPLAY
                                                       ↓
                                                 Skill Profile
                                                       ↓
                                            Adaptive Persona 추천
                                                       ↓
                                                   다음 소개팅
```

### 9. 경쟁 서비스 / 차별화 방향

대표적인 AI Dating Coach 서비스로 **Winkply**가 있으며, AI 음성 롤플레이와
영상 기반 body language·eye contact·smile 분석 등을 제공한다.

따라서 단순한 **AI 소개팅 연습 + 표정 분석**만으로는 차별성이 부족하다.

우리 서비스는 다음 3가지를 핵심 차별점으로 가져간다.

1. **DATE REPLAY** — 영상·음성·대화를 동일 타임라인에서 복기
2. **Skill Profile** — 사용자의 대화 역량을 세션마다 누적 분석
3. **Adaptive Persona** — 사용자의 약점에 맞춰 다음 AI 상대 자체를 변경

### 10. 서비스 핵심 흐름

1. AI 소개팅 상대 선택
2. Webcam + 음성으로 실제 소개팅처럼 대화
3. AI가 영상·음성·대화를 실시간 분석
4. 소개팅 종료
5. DATE REPLAY로 주요 순간 복기
6. 개인 Skill Profile 갱신
7. AI가 현재 약점 분석
8. 약점을 훈련하기 위한 다음 Persona 추천
9. 다시 소개팅 → 성장 비교

### 11. 의도적으로 제외한 기능

| 기능                 | 제외 이유                        |
| -------------------- | -------------------------------- |
| 외모·매력도 점수     | 주관적이고 신뢰성이 낮음         |
| 상대방 호감도 예측   | 실제 감정을 AI가 확정하기 어려움 |
| 데이팅앱 메시지 작성 | 서비스 핵심과 거리가 있음        |
| 프로필 사진 평가     | 기존 서비스와 차별성 약화        |
| 실제 사용자 매칭     | 6주 MVP 범위 초과                |

### 12. 프로젝트 핵심

## 막힌 것 / 의문

1. **웹캠 포즈 추정이 교실 환경에서 실제로 될까?**
   여러 명이 한 화면에 잡히고, 책상 아래로 들어가면 몸이 가려진다.
   가려진 상태에서 "머리 보호 자세"를 판정할 수 있는지 확인이 필요하다.

2. **FIRST DATE AI의 실시간성 — 지연이 얼마나 나오나?**
   `STT → LLM → TTS` 왕복이 대화로 느껴지려면 몇 초 안에 끝나야 하는데,
   스트리밍으로 붙여도 감당되는 수준인지 수치로 재봐야 한다.

3. **멀티모달 "동시" 분석의 기준 시각을 어떻게 맞추나?**
   영상 프레임과 음성 세그먼트, STT 결과의 타임스탬프를 하나의 타임라인에
   정렬해야 DATE REPLAY가 성립한다. 동기화 설계가 필요하다.

4. **Skill Profile의 지표를 무엇으로 검증하나?**
   "후속 질문 능력 72점"이 맞는 점수인지 확인할 정답 데이터가 없다.
   정답 없이도 신뢰를 주는 방식(상대 비교, 변화량 중심)이 필요할 듯하다.

5. 두 후보 중 하나를 골라야 하는데, **6주 MVP 안에 끝나는 쪽**이 어디인지 아직 판단이 안 된다.
