## 공부한 것

### 1. 스폰서십 노출 측정 산업

이미 존재하는 시장이다. Nielsen Sports, Relo Metrics 같은 회사가
"우리 브랜드가 이 경기 중계에서 얼마짜리 노출을 받았나"를 리포트로 판다.

기존 방식의 한계를 알아둘 것:

- 상당 부분이 **수작업 태깅**이거나 샘플링 기반
- 그래서 비싸고 느리다 → 자동화 여지가 여기 있다

### 2. EV(Exposure Value) 라는 개념

핵심은 **노출을 시간만으로 재면 안 된다**는 것.

```
EV = Σ_frames ( 노출 면적비 × 가시성 품질 × 순간 중요도 ) × 단가 환산
```

| 항목            | 의미                                 |
| --------------- | ------------------------------------ |
| 노출 면적비     | 광고판이 화면에서 차지하는 픽셀 비율 |
| 가시성 품질     | 가려짐, 블러, 잘림 정도              |
| **순간 중요도** | 그 순간이 얼마나 중요한 장면인가     |
| 단가 환산       | CPM, 시청자 수, 리그 등급            |

**오늘 가장 중요한 깨달음**: 골 장면의 10초와 중원 패스 장면의 10초는 같은 값이
아니다. 광고주가 사는 것은 "화면에 떠 있던 시간"이 아니라 "사람들이 보고 있던
시간"이다. 그래서 **순간 중요도 곡선**이 EV 수식의 독립적인 항으로 필요하다.

이게 나중에 "액션 라벨 → 중요도 곡선" 모듈이 왜 있어야 하는지의 근거가 된다.

### 3. 문제 분해

한 덩어리로 보면 못 푼다. 다섯 단계로 쪼갠다.

```
1. 탐지     프레임에서 광고판이 어디 있는가
2. 식별     그 광고판이 어느 브랜드인가        ← 여기가 제일 어려울 것 같다
3. 연결     프레임 간에 같은 광고판을 이어붙이기
4. 정량화   면적 × 시간 × 가시성 누적
5. 환산     중요도 가중 + 단가 적용 → 금액
```

2번이 병목일 것으로 예상. 텍스트를 읽든(OCR), 생김새를 비교하든(임베딩),
특징점을 맞추든(피처 매칭) 어느 하나는 돼야 한다.

### 4. 데이터셋 조사 — SoccerNet

| 항목   | 내용                                                                        |
| ------ | --------------------------------------------------------------------------- |
| 규모   | 유럽 6대 리그 방송 중계 550경기                                             |
| 해상도 | 720p, 25fps                                                                 |
| 라벨   | 액션 스포팅, 카메라 샷 분할, 리플레이 그라운딩, 캘리브레이션, 트래킹, re-ID |
| 접근   | 영상은 NDA 필요, 라벨은 공개                                                |

**광고판 라벨은 없다.** 이 프로젝트가 새로 만들어야 하는 부분이다.
→ 그래서 **합성 데이터**로 탐지기를 사전학습하는 경로를 미리 염두에 둬야 한다.

## 막힌 것 / 의문

1. **720p에서 광고판 글자가 읽힐 만큼 크게 잡히나?**
   중계 화면을 떠올려 보면 광고판은 화면 아래쪽에 얇은 띠로 지나간다.
   글자 높이가 10px도 안 될 것 같은데, 그러면 OCR이 성립할까?
   → 이건 반드시 **숫자로 확인해야 한다.** 감으로 결정하면 안 되는 부분.

2. 영상이 없는 동안 뭘 할 수 있나? 라벨만으로 할 수 있는 게 있을까?

3. 광고판 추적에 ByteTrack 같은 객체 추적기를 쓰는 게 맞나?
   추적 대상이 사람이 아니라 **정지해 있는 판**인데, 사람 추적용 도구가 맞을까?
