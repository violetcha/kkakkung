## 오늘의 목표

OCR이 안 될 가능성에 대비해 **브랜드 식별 대안 경로**를 조사한다.

## 공부한 것

### 1. 브랜드 식별의 세 가지 경로

| 경로 | 원리 | 강점 | 약점 |
|---|---|---|---|
| A. OCR | 글자를 **읽는다** | 정답이 명확, 미등록 브랜드도 읽힘 | 작으면 완전 실패 |
| B. 임베딩 | 생김새를 **비교한다** | 글자 아니어도 됨(순수 로고) | 열화에 약함 |
| C. 로컬 피처 | 특징점을 **맞춘다** | 평면 rigid에 유리, 위치까지 나옴 | 텍스처 부족하면 실패 |

축구 LED 보드는 대부분 브랜드명 **텍스트**라 A가 주 경로가 될 가능성이 높다.
하지만 어제 계산대로면 A가 무너질 수 있으니 B, C를 반드시 같이 재봐야 한다.

### 2. CLIP vs DINOv2 — 이 차이가 중요하다

| | CLIP | DINOv2 |
|---|---|---|
| 학습 방식 | 이미지-텍스트 대조 학습 | 자기지도 (self-distillation) |
| 잘하는 것 | **의미(semantic)** 수준 유사도 | **개체(instance)** 수준 유사도 |
| 예시 | "이 둘 다 자동차 사진이다" | "이 둘은 **같은** 자동차다" |

**브랜드 식별은 instance-level 문제다.** "둘 다 로고다"가 아니라
"이 둘은 같은 브랜드 로고다"를 알아야 한다.
→ 이론상 DINOv2가 더 맞을 것 같다. 하지만 **실제로 재봐야 안다.**
CLIP 하나만 쓰고 결론 내리면 안 되는 이유.

DINOv2 임베딩 추출 팁: CLS 토큰만 쓰는 것보다 **CLS + 패치 평균을 이어붙이면**
성능이 더 좋다고 알려져 있다.

### 3. 로컬 피처 세 가지

| 검출기 | 기술자 | 특징 |
|---|---|---|
| SIFT | 128차원 실수 | DoG 스케일 스페이스. **스케일/회전 불변**. 느리지만 강력 |
| ORB | 256bit 이진 | FAST + BRIEF. 매우 빠름. **스케일 피라미드 범위 제한** |
| AKAZE | 이진 | 비선형 확산 필터. 엣지 보존 |

**ORB의 함정**: 스케일 커버리지가 `scaleFactor^(nlevels-1)`로 제한된다.
기본값(1.2, 8레벨)이면 약 3.6배까지만 커버한다. 등록 로고 템플릿과 화면 속
광고판의 크기 차이가 그보다 크면 **구조적으로 못 찾는다.**
SIFT는 스케일 불변이라 이 문제가 없다. → 비교할 때 이 점을 감안해야 공정하다.

**Lowe ratio test**: 최근접 이웃과 2번째 이웃의 거리 비가 임계(보통 0.7~0.8)보다
작을 때만 유효 매칭으로 인정. 반복 패턴이 많으면 1등과 2등이 비슷해져서 대량 탈락한다.
→ **글자처럼 획이 서로 닮은 대상에서는 이게 불리하게 작동할 수 있다.**

### 4. 평가 지표 — "된다"를 어떻게 증명할 것인가

이게 오늘 배운 것 중 제일 중요할지도.

**(a) OCR: 완전일치 vs 편집거리**

완전일치만 세면 "한 글자 틀림"과 "아무것도 못 읽음"이 똑같이 0점이 된다.
임계값 곡선이 왜곡되므로 **정규화 편집거리 유사도(1 − CER)** 를 같이 봐야 한다.

```
sim = 1 - levenshtein(pred, truth) / len(truth)
```

단, 최종 판정은 완전일치로. **브랜드를 잘못 붙이면 광고주에게 남의 노출을
청구하는 셈**이라 부분 일치는 실무에서 의미가 없다.

**(b) 임베딩: 분포가 겹치는가**

정확도 하나로 말하면 안 된다. 같은 브랜드 쌍의 유사도 분포와 다른 브랜드 쌍의
분포를 **같은 축에 겹쳐 그리고**, 겹치면 못 쓰는 것이다.

| 지표 | 의미 |
|---|---|
| ROC-AUC | 무작위로 뽑은 양성이 음성보다 높을 확률. 0.5=무작위 |
| **EER** | 오수락률 = 오거절률이 되는 지점의 오류율. **실전 성능에 가장 가깝다** |
| 히스토그램 겹침 | 0=완전분리, 1=완전중첩 |

**(c) 로컬 피처: 재현율만 보면 안 된다**

임계를 낮추면 재현율은 얼마든지 올릴 수 있다. 반드시 **장면에 없는 브랜드를
질의해서 거짓양성률도 같이 재야 한다.**

그리고 인라이어 개수만으로 성공 판정하면 안 된다. 호모그래피가 퇴화하면
투영된 사각형이 뒤집히거나 선으로 눌린다. → **볼록성과 종횡비도 검사**할 것.

**(d) 표본이 작을 때 — Wilson score 구간**

시행 12번에 12번 성공했다고 "재현율 100%"라고 쓰면 안 된다.
Wilson 구간으로는 `[0.76, 1.00]`이다. 작은 표본에서 정규근사보다 정직하다.

### 5. 합성 데이터 / Domain Randomization

SoccerNet에 광고판 라벨이 없으니 만들어야 한다.

**합성의 결정적 장점**: 합성 위치를 알고 있으니 **라벨이 자동 생성된다.**
그리고 "글자 높이 10px"를 정확히 만들 수 있어서 **임계값 측정에 이상적이다.**
실사로는 GT 높이를 정확히 알 수 없다.

**합성의 함정**: 너무 깨끗하게 만들면 실제보다 쉬운 문제가 된다.
슈퍼샘플링 후 축소하면 안티에일리어싱이 이상적이라 실사보다 잘 읽힌다.
→ **합성으로 잰 임계값은 낙관적 하한으로 봐야 한다.**

재현할 열화 요인:
원근, 밝기/대비, 모션 블러, 부분 가림, JPEG 압축, 노이즈,
그리고 LED 특유의 **자체 발광(가산 합성)** 과 **주사 밴딩**.

### 6. YOLO OBB

광고판은 원근 때문에 기울어진 사변형이다. 축 정렬 bbox로 라벨링하면
배경이 크게 포함되어 손실이 크다. → **회전 박스(OBB)** 형식을 같이 내보내는 게 맞다.

```
YOLO bbox : class cx cy w h            (정규화)
YOLO OBB  : class x1 y1 x2 y2 x3 y3 x4 y4
```

OBB의 부수 효과: **네 모서리를 알면 원근 역보정이 가능하다.**
광고판은 평면이라 호모그래피로 완전히 정면화된다.
