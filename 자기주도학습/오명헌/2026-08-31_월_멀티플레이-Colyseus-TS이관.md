## 공부한 것

### 1. 정직한 신호는 거리 측정기가 된다

심장박동을 그것과의 거리에 **선형**으로 물려놨었다. 문제는 **너무 잘 동작한다**는 것.
플레이어가 귀로 눈금을 읽고 **대비할 수 있게 된다.** 공포는 대비하는 순간 사라진다.

```js
const near = Math.pow(d, 2.4);   // 멀 때는 거의 안 변하고 코앞에서 치솟는다
```

같은 이유로 **긴장 클러스터를 통째로 지웠다.** 켜졌다/꺼졌다가 곧
"시야에 있다/없다"라는 1비트를 정확히 알려주는 장치였다.

> 감각적 연출과 정보 누설은 같은 것이다. "이 소리에서 무엇을 알아낼 수 있는가"를 먼저 따진다.

### 2. 정보 비대칭은 UI가 아니라 전송에서 막는다

술래는 도망자 위치를, 도망자는 탈출구 위치를 모른다. **화면에서 가리면
개발자 도구를 여는 순간 무너진다.** 그래서 `viewFor(game, id)` 가 사람마다 다른 패킷을 만든다.

| 받는 사람 | 들어 있는 것 | 없는 것 |
|---|---|---|
| 도망자 | `exitDist`(칸 수) | 탈출구 좌표 |
| 술래 | `hints`(방향·거리) | 도망자 좌표 |

> 규칙이 "모른다"면 **데이터가 도착하지 않아야** 진짜로 모르는 것이다.

### 3. 순수 로직 분리의 값을 하루 만에 회수했다

오전에 `ws` 로 짠 서버를 오후에 Colyseus로 갈아엎었는데
**`rules.ts`·`maze.ts` 는 한 줄도 안 고쳤고 테스트 360건이 그대로 통과했다.**

가능했던 이유: `maze` 에 네트워크·타이머·상태를 안 넣었고, `rules` 가 **`Date.now()` 를 안 부른다.**
시간을 인자로 받으니 **5분짜리 라운드를 테스트에서 한 줄로** 끝낸다.

> 순수 함수는 우아함이 아니라 **갈아엎을 때 살아남는 범위**를 정하는 일이다.

### 4. 계층 경계에서 죽는 버그 — `maxPayload` 4KB

얼굴 스냅샷을 보내면 **연결이 그냥 끊겼다.** 앱 레벨 크기 검증(`FACE_MAX`)이 있었지만
**거기까지 도달하지 못했다.** WebSocket 기본 `maxPayload` 가 4KB라 전송 계층이 먼저
코드 1009로 소켓을 끊는다. **거부는 이유를 말하지만 절단은 아무 말도 안 한다.**

```ts
new WebSocketTransport({ server, maxPayload: 96 * 1024 })  // 거부는 방에서 한다
```

**왜 테스트가 못 잡았나** — 얼굴 픽스처가 400B짜리 가짜 JPEG였다. 한도를 못 건드리니 통과했다.
실제 크기(20KB)로 바꾸고, "거부되는가"만이 아니라 **"거부돼도 연결이 살아 있는가"** 도 검사에 넣었다.

> 검증은 **이유를 말할 수 있는 계층**에서 해야 한다.
> 그리고 픽스처가 실물보다 작으면 크기 관련 버그는 구조적으로 안 잡힌다.

### 5. 매치메이킹 필터에서 두 번 넘어졌다

- **`setPrivate(true)` 를 쓰면 안 된다** — 방이 매치메이킹에서 통째로 빠져 **같은 코드를 든 사람조차 못 들어온다**
- **`code` 를 생략하면 안 된다** — 필터가 무력해져 코드 있는 방까지 후보로 잡힌다. 공개 방은 빈 문자열을 **명시적으로** 보낸다

`undefined` 와 `''` 는 필터에게 **"묻지 마"와 "빈 값을 찾아"** 로 정반대다.
그리고 `filterBy` 는 방어가 아니다 — `joinById` 우회가 남아 **`onAuth` 에서 코드를 다시 검사**한다.

> "찾기 어렵게 하는 것"과 "못 들어오게 하는 것"은 다른 계층의 일이다.

### 6. TypeScript는 문서가 아니라 못이다

이관 이유는 취향이 아니었다. **`viewFor()` 의 객체 모양을 양쪽이 관례로만 맞추고 있어서,
서버에서 `exitDist` 를 고치면 도망자 심장박동이 조용히 죽는** 구조였다.

- **`onLeave(client, consented)`** — 선언은 `number`, 런타임은 `boolean`. 그대로 뒀으면 **재접속이 조용히 실패**
- **`SoundHint` 타입** — "술래 힌트에 좌표가 없다"(§4.3 ②)를 `nettest` 가 런타임에 보던 것이 이제 **컴파일 단계 보장**이다. 넣으려 하면 빌드가 깨진다

> 테스트는 **어긴 것을 알려주고**, 타입은 **어길 수 없게 한다.**

**Node 24 타입 스트리핑** 때문에 `erasableSyntaxOnly` 를 켰다 — `enum` 은 런타임 객체를
만들어내니 "타입만 지운다"는 전략과 애초에 양립하지 않는다. 제약이 자의적인 게 아니라 정의 그 자체다.

### 7. 순환 참조는 의존 방향을 뒤집어 끊는다

`src/main.ts` 1,800줄을 쪼개려 하니 `audio ↔ net`, `player ↔ net` 순환이 나왔다.
`import` 로는 못 푼다. **한쪽 방향을 뒤집어야 한다.**

| 전 (당긴다) | 후 (민다) |
|---|---|
| `audio` 가 `net` 에서 가져온다 | `net` 이 `setExitDread()` 로 밀어넣는다 |
| `player` 가 `net` 을 부른다 | `net` 이 `setSender()` 로 자기를 꽂는다 |

핵심은 **"필요한 쪽"과 "가지러 가는 쪽"이 같을 필요가 없다**는 것.
결과적으로 의존이 한 줄기가 됐고 `main.ts` 는 **1,826줄 → 87줄**(렌더 루프만) 남았다.

```
core/space · core/dom → scene → audio → player → minimap·quality·face·net → main
```

### 8. 완전미로는 술래잡기에 최악이다

재귀 백트래커의 결과물(유일 경로)은 알고리즘 교과서의 목표이고 이 게임에는 최악이다 —
**도망자가 막다른 길에 들어가는 순간 게임이 끝난다.**
그래서 **막다른 칸의 72%를 뚫어 고리를 냈다.** 고리가 있어야 추격이 게임이 된다.

> 자료구조의 좋은 성질이 게임의 좋은 성질과 반대일 수 있다. 알고리즘을 **망가뜨려야** 할 때가 있다.

### 9. 규칙 결함을 사람 없이 숫자로 확정했다

금요일에 종이에서 발견한 "같은 속도면 거리가 불변"을 25판×3설정 시뮬레이션으로 확정했다.

| 설정 (술래/도망자) | 포획 | 평균 |
|---|---|---|
| 같은 속도 400/400 | **8/25** | 11.1초 |
| 차등 360/400 | 20/25 | **22.2초** |
| **A안 320/400** (적용) | 20/25 | 13.0초 |

우려는 사실이었다. 그런데 **360/400이 더 나을 수 있다** — 포획률은 같은데 추격이 1.7배 길다.

> 좋은 밸런스는 "잡히는가"가 아니라 **"얼마나 오래 쫓기는가"** 다. 승률만 봤으면 둘이 같아 보였다.

### 10. 나머지 — 짧게

- **대역폭 절반** (9.01 → 4.50 KB/s) — 미로를 매 틱 보내던 걸 판마다 한 번으로. **주기 패킷에서 안 변하는 것 찾기**가 가장 싼 최적화다
- **자동 품질** — 사다리보다 **병목 구분**이 핵심. `추론 ms > 14` 면 메인 스레드가 막힌 것이라 화질을 깎아도 안 나아진다. 금요일에 몸으로 배운 실패의 자동화
- **히스테리시스가 또 나왔다** — 프레임 13~22ms 구간에서는 아무것도 안 한다. 얼굴 입력 게이트와 **같은 문제**(연속값으로 이산 결정을 내릴 때의 채터링)
- **테스트가 코드 구조에 기생하고 있었다** — HTML을 정규식으로 잘라 `new Function` 으로 돌리던 것을 `import` 로. 모듈화의 이득은 재사용보다 **테스트 가능성**으로 먼저 온다
- **고정 `sleep` 대신 상태 대기** — 포트는 기동 메시지보다 먼저 열린다. 기다림의 조건은 시간이 아니라 관측 가능한 상태여야 한다

## 막힌 것 / 남은 의문

1. **여전히 이 게임 화면을 직접 본 적이 없다.** 서버 프로토콜·문법·오디오 그래프·미니맵 로직만
   **기계로** 검증했다. 로비 UI, 상대가 보이는 모습, 미니맵 가독성은 눈으로 봐야 한다
2. **점프스케어 — 문서와 코드가 충돌한다.** §2.3은 금지인데 스팅어가 정확히 그것이다.
   지금은 **문서를 안 고친 채 코드만 어긴 상태**
3. **320/400 vs 360/400** — AI 기준이라 사람으로 재봐야 한다
4. **6인 · 술래 2명 밸런스** — 4명 중 1명만 나가도 도망자 승이다
5. **`strict: false` 가 아직 남아 있다.** 모듈 분할이 끝났으니 이제 조일 수 있다.
   임시 완화를 임시로 유지하는 게 제일 위험하다
6. **Colyseus 버전을 못 올린다** — 0.16은 npm 배포가 깨져 있고(`workspace:^` 잔존), 0.18은 짝이 되는 클라 SDK가 없다
