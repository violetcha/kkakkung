# 3. DB 덤프

**해당 없음.** 까꿍은 데이터베이스를 쓰지 않는다. 그래서 DB 덤프 파일, DB 접속 정보, ERD가 없다.

## 데이터를 두는 곳

| 데이터                        | 저장 위치                                                                                     | 수명                   |
| ----------------------------- | --------------------------------------------------------------------------------------------- | ---------------------- |
| 방·자리·세션·경기 상태        | 게임 서버 메모리                                                                              | 방이 닫히면 사라진다   |
| 대기실 가공 얼굴 사진         | 게임 서버 메모리(같은 방에만 전달)                                                            | 나가면 지운다          |
| 카메라 원본·가공 얼굴 영상    | 저장하지 않는다(브라우저 → LiveKit 실시간 중계)                                               | —                      |
| 미디어 권한 회수 기록         | 컨테이너 볼륨 `/var/lib/kkakkung/media-journal.jsonl`(+ `.checkpoint.json`)                   | 서버 재시작 복구용     |
| LiveKit 사용량 예약 기록      | 같은 볼륨의 `usage-checkpoint.json`                                                           | 월 사용량 가드용       |
| 회수 재시도 기록              | 같은 볼륨의 `cleanup-checkpoint.json`                                                         | 서버 재시작 복구용     |
| 운영 설정                     | 호스트 `/opt/kkakkung/runtime-evidence/`(`service-operations.json`, `capability-report.json`) | 운영자가 관리          |
| 운영자 이메일 목록            | 호스트 `/opt/kkakkung/sso-access/allowed-emails.txt`                                          | 운영자가 관리          |
| 브라우저 설정(음량·품질·동의) | 각 사용자 브라우저 `localStorage`                                                             | 사용자가 지우기 전까지 |

운영 기록 파일에는 회원 정보나 경기 결과가 없다. 미디어 세대 식별자와 상태, 사용량 수치만 들어 있어 제출용 덤프 대상이 아니다.
