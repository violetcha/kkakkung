까꿍으로 돌아가기

오픈소스 고지

까꿍의 얼굴·자세·손동작 인식에는 Google의 MediaPipe 비전 자산을, 화면 글꼴에는 갈무리 픽셀 글꼴을, 경기 배경음에는 Philippe Groarke의 Dark ambiance를 사용합니다.

이 페이지는 이 자산들의 출처와 확인한 라이선스를 안내합니다. 확인일: 2026-09-18.

확인한 라이선스

  • MediaPipe Tasks Vision SDK 1.0.1: 패키지에 명시된 Apache-2.0.
  • FaceLandmarker float16 release 1: BlazeFace, Face Mesh V2, Blendshape V2 모델 카드의 Apache-2.0.
  • PoseLandmarker Lite float16 release 1: BlazePose GHUM 3D 모델 카드의 Apache-2.0.
  • GestureRecognizer의 손 검출·랜드마크 구성 모델: Hand Tracking 모델 카드의 Apache-2.0.

직접 만든 자산

미로의 벽·바닥 질감, 캐릭터와 장비 형상, 효과음과 안내음, 로고는 이 프로젝트가 직접 만들었습니다. 외부에서 받은 그림·모델·음원 파일은 위에 적은 것 외에 없습니다.

추가 확인 중인 항목

GestureRecognizer의 gesture embedder·canned gesture classifier는 공식 분류 모델 카드에 라이선스 항목이 없어 재배포 조건 확인이 남아 있습니다. SDK의 라이선스를 해당 모델의 권리로 대신하지 않습니다.

SDK에 포함된 제3자 구성 요소의 고지도 추가 확인 중입니다. 이 페이지는 서비스 전체의 권리 검토 완료를 뜻하지 않습니다.
